Initial commit: Forge networking platform prototype

Forge is a professional networking platform for the Richfield/AAA
community, built for the 2026 Richfield Hackathon. It connects
students, alumni, business users, and campus administrators around
portfolios, connections, opportunities, and career pathways.

User roles
- Student: institutional-email signup (@my.richfield.ac.za,
  @richfield.ac.za, @my.aaa.ac.za, @aaa.ac.za), portfolio profile,
  applies to opportunities, connects with peers/alumni
- Alumni: no active student email; identity verified via a manual
  document-upload + admin-approval review queue
- Business user: recruiter/employer; admin approval required before
  posting opportunities; cannot see student data beyond what's
  explicitly made visible
- Administrator: provisioned separately, never self-registered;
  manages users, moderation, events, opportunity approval, analytics,
  announcements

Core features
- Connections + activity feed, direct messaging
- Opportunity board with skill-based matching
- Career pathway explorer
- AI profile coach / onboarding assistant (Anthropic API when
  ANTHROPIC_API_KEY is set, rule-based fallback otherwise)
- CV-based skill extraction
- Video posts with transcoding
- Real-time notifications over WebSocket (Flask-SocketIO)
- Three analytics dashboards: student, business, admin

Stack
- Backend: Flask + Flask-SQLAlchemy (SQLite for dev, migrates to
  Postgres)
- Realtime: Flask-SocketIO
- Auth: server-side sessions + Werkzeug password hashing, with
  institutional-domain filtering and a non-self-registerable admin
  role enforced directly on the backend
- Frontend: single Flask-served HTML/JS client (forge_demo.html)

Known gap: the brief calls for a mobile app in Flutter, React Native,
.NET MAUI, or native Kotlin/Swift. This prototype is a Flask-served
web client instead — flagged in the README, with a mitigation plan to
cover in the presentation.
